# School Management System

Sistema web de gestión escolar desarrollado con Node.js, MySQL y JavaScript.

![GitHub repo size](https://img.shields.io/github/repo-size/TomasBuitragoL11/School-Managment-System.git)
![GitHub last commit](https://img.shields.io/github/last-commit/TomasBuitragoL11/School-Managment-System.gitm)

## Descripción

Plataforma educativa integral que permite la gestión de estudiantes, profesores, materias, calificaciones, tareas y comunicación interna entre los usuarios del colegio.

## Roles del sistema

| Rol | Funcionalidades |
|---|---|
| Administrador | Gestión de usuarios, materias y horarios |
| Profesor | Registro de notas, creación de tareas, mensajería |
| Estudiante | Consulta de calificaciones, horario y entregas |

## Tecnologías

- **Backend:** Node.js, Express
- **Base de datos:** MySQL
- **Frontend:** HTML, CSS, JavaScript
- **Autenticación:** JSON Web Tokens, bcrypt
- **Diseño:** Responsive para móvil y escritorio

## Instalación

```bash
git clone https://github.com/TomasBuitragoL11/school-management-system
cd school-management-system/backend
npm install
node server.js
```

## Variables de entorno

Crear un archivo `.env` en la carpeta `backend`
